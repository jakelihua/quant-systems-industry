# 二十一类量化岗位进阶课程

先完成共用的四条链路，再按岗位族深挖。第一条从市场数据的可用时间到信号，第二条从组合目标到成交，第三条从成交到账本与清算，第四条从事故证据回到测试和发版。以下每一行都写明技术之所以适用，以及达到什么标准才算做完。[行业岗位证据](../catalog/jd-catalog.md)

| 岗位族 | 日常交付与技术选型 | 项目入口与验收 |
|---|---|---|
| QR 量化研究 | 产出可证伪假设和成本后净效用。NumPy/pandas 适合横截面研究，回测同时检查日期、标的、成交和权重 | [实验 R1](09-experiment-log.md#r1-真实行情前推)；重做逐年候选选择、基准敏感性和反证 |
| ML 金融机器学习 | 产出有时点的训练集、可重跑模型和有效性报告。线性/树基线成本低，PyTorch/TensorFlow 适合需要自定义可微目标和大规模训练 | [实验 R2](09-experiment-log.md#r2-模型漂移)；时间外与零预测比较，无效时记录拒绝理由 |
| QD 量化开发 | 将研究接口与生产输入、输出、交易时钟和版本对齐。Python 适合研究 API，C++ 可承接确认的热点 | [实验 R1](09-experiment-log.md#r1-真实行情前推)、[实验 E1](09-experiment-log.md#e1-订单账本)；用同一输入对照回测与回放，列出模型差异 |
| DATA 数据科学与行情数据 | 建设 schema、参考数据、数据字典、版本和质量规则。SQL/Parquet 支持查证和离线审计，kdb+/q 或列式库适配特定时序/分析负载 | [实验 D1](09-experiment-log.md#d1-pit-与盘口恢复)；延迟修订不回填到决策过去，断流时停止对外输出 |
| PORT 组合管理与投资实施 | 把信号做成目标仓位，解释风险、容量和换手。大规模用可处理约束的优化器，同时保留小参考实现作交叉验证 | [实验 P1](09-experiment-log.md#p1-约束组合与对账)；对比受限/不受限，解释目标和交易约束何时冲突 |
| INDEX 指数与 ETF | 产出指数重构和跟踪差异。版本化指数方法、生效价、权重、股息、停复牌、替代篮子与 FX 规则 | [ETF 盘](02-desk-guide.md) 与 [实验 V1](09-experiment-log.md#v1-利率外汇与基金估值)；设计换样回放，区分价格指数、总回报和基金费用 |
| TRADE 量化交易与执行 | 锁定母单目标、参与率、成交基准、风险与异常处理。从 FIX/专有协议还原回报，按订单键关联行情与动作 | [实验 E1](09-experiment-log.md#e1-订单账本)；手算到达价 IS；比较完成率和净成本，说明未成交机会成本 |
| MICRO 高频微观结构与做市 | 把订单、撤单和成交读成可审计序列，展示价差捕获、markout、库存及延迟 | [实验 M3](09-experiment-log.md#m3-做市损益)、[实验 D1](09-experiment-log.md#d1-pit-与盘口恢复)；两种分析解释同一组合为何价差盈利、最终亏损 |
| FICC 期货、利率、信用与外汇 | 分开研究价格变化、结算、carry、信用利差、汇率和融资。合约级台账避免连续合约跳点，曲线风险按期限桶表达 | [实验 M1](09-experiment-log.md#m1-期货换月) 与 [实验 V1](09-experiment-log.md#v1-利率外汇与基金估值)；复算盯市、追保、DV01、FX 点差口径 |
| DERIV 衍生品定价与波动率 | 同期限同步标的和 bid/ask 反解 IV；模型适配欧式/美式、分红、利率与结算。压力收益用全量重估对照 Greeks 近似 | [实验 M2](09-experiment-log.md#m2-期权压力重估)；通过 put-call parity、反解和大冲击重估，定义 vega 单位 |
| RISK 投资、市场与模型风险 | 产出限额、敞口、TE、ES、情景和独立模型验证。分清事后历史风险、估计风险、实时可用资金 | [实验 R1](09-experiment-log.md#r1-真实行情前推)、[实验 R2](09-experiment-log.md#r2-模型漂移)；指出回测结果被拒绝时是哪条规则 |
| SYS 低延迟系统与交易基础设施 | 行情到决策/发单的延迟拆成解析、排队、状态、网络；C++/Rust、Linux profiling、网络拓扑或绑核在具体热点出现时评估 | [实验 S1](09-experiment-log.md#s1-c-价格档基准)；满足确定性输出后报告负载和数据结构适用范围 |
| HW FPGA 与硬件 | 在确定延迟/吞吐约束下设计 RTL 或硬件 pipeline，硬件、时钟、定点、host interface 和回退均有边界 | [实验 S1](09-experiment-log.md#s1-c-价格档基准) 作软件基线；独立课题做小型 RTL 和逐包 golden vectors，验收误包、溢出、回压与资源利用率 |
| OPS 生产工程与 SRE | 输出服务状态、水位线、处理延迟、事件相关性、事故时序与恢复指标。监控和日志各自避免高基数开销 | [系统运行册](04-systems-and-operations.md)；关采集、重启、补快照、重放；满足可证明的 readiness |
| POST 交易运营、基金核算与清算后台 | 对账、资金、可用量、结算和估值分账。事务库维护权威记录，分录与外部凭证有显式主键 | [实验 P1](09-experiment-log.md#p1-约束组合与对账)、[实验 V1](09-experiment-log.md#v1-利率外汇与基金估值)；对账区分错、缺、重、状态未达，核算单位净值 |
| CLEAR 交易所清算与流动性风险 | 关心保证金、变动保证金、可用抵押品、压损、集中和结算时点。清算机构的组合风险模型比单合约保证金公式复杂 | [实验 M1](09-experiment-log.md#m1-期货换月)；写跨账户压力作业，按时间检验现金和抵押品可用 |
| AI 智能化与 AI 应用 | Agent 把查询、告警和证据串起来；规则、检索、工作流和模型各做对照。将审批、权威账本和执行保持为确定性接口 | [智能化运行手册](04-systems-and-operations.md)；用人工标注事件，检查证据覆盖与权限；模型本身是扩展作业 |
| MLOPS 研究平台与 ML 基础设施 | 用容器、调度和制品版本管理代码、样本、模型、特征；DDP/AMP 要在真实瓶颈和精度成本验证后启用 | [实验 R2](09-experiment-log.md#r2-模型漂移)；提交训练数据哈希和特征版本，测发布与回退；GPU 实验需自备运行环境 |
| COMP 合规、监控与控制 | 定义业务控制、异常监控、证据留存和权限；区分触发规则、人工调查和结论，记录适用场所及版本 | [系统运行册](04-systems-and-operations.md)；用重复、迟到和部分成交场景测告警误报及审计重现 |
| UI 全栈界面与量化数据产品 | React/TypeScript 或受控浏览器渲染管理复杂状态。画面标行情时间与来源、数据失效和待确认状态，UI 与 API 不重复做权威决策 | 离线包中的研究看板；校验不同区间的净值重新锚定、快照版本和导出值。选做 OMS 状态面板 |
| PROD ETF 及量化产品运营 | 关联基金规则、净值、规模、资金流、跟踪差异和披露证据。报告口径需要作业内与客户两个版本 | [实验 V1](09-experiment-log.md#v1-利率外汇与基金估值)；同一日同时说明规模上升与投资回报为负，给出数据血缘 |

## 按顺序进阶

| 模块 | 建议时长 | 讲义 | 交付 |
|---|---:|---|---|
| 行业与业务设计 | 1 周 | JD 目录、技术选型、市场手册 | 把目标机构每条岗位职责映射到系统和验收证据 |
| 研究与组合 | 3 周 | 研究和风控、实验 R1/R2/P1 | 研究卡、前推结果、约束组合、模型拒绝记录 |
| 定价与盘面 | 3 周 | 量化看盘、M1/M2/M3/V1 | 期货换月簿、期权曲面切片、做市 P&L、FX/利率估值 |
| 数据、交易和清算 | 3 周 | 系统运维、D1/E1/P1 | PIT 查询、订单状态回放、对账表及恢复手册 |
| 工程、运维与智能化 | 2 周 | 技术选型、S1、智能化运行手册 | 延迟报告、上游故障演练、AI 诊断基线评估设计 |
| 结项证据 | 2 周 | 结项验收与学习日志 | 可运行作业、事故复盘、口头答辩与公众号文章 |

建议每周 8–12 小时。完成核心作业后，为目标岗位额外完成两项专业作业。真实 L2、历史期权链、券商接口、FPGA/GPU 配置等需要数据或环境，按对应模块的自备条件开展。
